# Proyecto Turismo

Bienvenido al repositorio **proyecto-turismo**, una plataforma diseñada para promover y facilitar el acceso a actividades turísticas y emprendimientos locales.

## 🧭 Descripción

Este sistema está orientado a mejorar la experiencia del visitante y fortalecer los emprendimientos locales a través de una app moderna, intuitiva y eficiente.

## 📦 Tecnologías utilizadas

Dependiendo del módulo, se usan distintas tecnologías:

### 🌐 Frontend
- **React** (para la versión web)
- **Flutter** (para la app móvil)

### ⚙️ Backend
- **Spring Boot** (Java)

### 🗄️ Base de datos
- **MySQL**

## 🚀 Características principales

- Búsqueda de emprendimientos por categoría.
- Reservas online.
- Calificaciones y reseñas.
- Escaneo de códigos QR para ver información del lugar.
- Panel de administración para la municipalidad.

¡Gracias por visitar! 🌍✨
